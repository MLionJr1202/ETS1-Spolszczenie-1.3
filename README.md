## 🇵🇱 Wersja Polska

### O projekcie
* **Ręczna robota:** Spolszczenie zostało przygotowane przeze mnie w pełni ręcznie – spędziłem 3 godziny nad dokładnym kodowaniem i dopracowywaniem plików tekstowych.
* **Poprawki niewidocznych błędów:** Uzupełniłem i poprawiłem braki z innych wersji (m.in. ze starych paczek z 2012 roku), w których wielu tekstów i komunikatów po prostu nie było widać na ekranie.
* **Pełna kompatybilność:** Działa bezproblemowo z aktualizacją **1.3** i bazuje na stabilnym układzie plików wersji niemieckiej (*German*).

### Jak pobrać i zainstalować?
1. Wejdź w zakładkę **Releases** (po prawej stronie ekranu) i pobierz najnowszy plik spolszczenia.
2. Wypakuj pobrane archiwum (jeśli jest w formacie `.zip` lub `.rar`).
3. Wejdź do folderu `Dokumenty\Euro Truck Simulator\mod`. **Jeśli nie masz tam folderu `mod`, utwórz go ręcznie** (z małych liter).
4. Wklej pobrany plik spolszczenia bezpośrednio do tego folderu `mod`.
5. Uruchom grę, wejdź w **Opcje** i jako język gry wybierz **German** (Niemiecki) – wtedy wczyta się pełny język polski.

## 🇬🇧 English Version

> **IMPORTANT NOTICE:** **This translation mod is in POLISH ONLY.** It translates the game interface and texts into the Polish language (it does not add English).

### About the Project
* **Handcrafted:** This Polish translation was created entirely by hand – I spent 3 hours coding and refining the text files from scratch.
* **Missing Text Fixes:** I fixed and restored missing lines from older releases (including 2012 packs), where many UI elements and messages were invisible on screen.
* **Full Compatibility:** Works seamlessly with the **1.3** patch and is built on top of the stable **German** language file structure.

### How to Download and Install
1. Go to the **Releases** section (on the right side of the page) and download the latest translation file.
2. Extract the downloaded archive (if it is in `.zip` or `.rar` format).
3. Navigate to `Documents\Euro Truck Simulator\mod`. **If the `mod` folder does not exist, create it manually** (all lowercase).
4. Place the downloaded translation file directly inside the `mod` folder.
5. Launch the game, go to **Options**, and select **German** as your game language – this will load the Polish language in-game.
